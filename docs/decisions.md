# open-gikai の判断ログ

goals.md の仮説・中目的について、線を引いた時と判断した時を残す表。**追記のみ**で、過去の行は書き換えない。
goals.md は「今の状態」、この表は「なぜそうなったか」を持つ。

| 欄 | 書くこと |
|---|---|
| 日付 | 判断した日（YYYY-MM-DD） |
| 対象 | 仮説（H◯）・中目的（M◯）の名前、または goals.md 全体 |
| 事前の線 | 判断の前に goals.md に書いてあった当たり・外れの線（転記） |
| 結果 | 指標の測定値と取得日 |
| 判断 | 起草 / 継続 / 方向転換（種類）/ 保留 / 停止 |
| 理由 | 1〜2 行 |
| 判断者 | 人（AI の提案 PR 番号）。合意前は「未合意」 |
