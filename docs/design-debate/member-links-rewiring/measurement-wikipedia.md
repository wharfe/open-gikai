# 実測: 選出職の Wikipedia 的中率（2026-09-04）

design A は「選出職にだけ Wikipedia を残す」、design B は「全員から削除する」と主張し、
どちらも的中率を測っていなかった。争点が実測で決着する種類だったので測った。

## 方法

`data/members.json` のキーが `m_` でないメンバー（＝議員名簿と突き合った人）から
`random.seed(42)` で40人を抽出し、ja.wikipedia.org の `action=query&titles=...` に
氏名をそのまま渡して存在を確認した。

## 結果

```
選出職サンプル 40人: Wikipedia 存在 38 / 不在 2  的中率 95%
不在の例: ['五十嵐えり', 'いんどう周作']
```

## 解釈

- **選出職にとって Wikipedia は404製造機ではない。** 95% が着地する。
- **外れた2人は「記事が無い」のではなく「表記が違う」**（平仮名の通称表記）。
  つまり残り5%も、記事の不在ではなく氏名正規化の問題である可能性が高い。
- したがって design B の「存在を保証できないから全員から削除」は、
  **保証できないことと当たらないことを同一視している**。676ページから
  的中率95%のリンクを消す代償に見合わない。
- 一方 `m_` 側（政府参考人・参考人）に同じ根拠は無い。design A / B が一致して
  Wikipedia を出さないと言っている区分なので、争点ではない。

## この計測が変えないこと

的中率は「リンクとして有用か」を答えるだけで、「どうやって選出職を判別するか」は答えない。
design A の3分類（`is_elected_member` の順序修正）と design B の2軸（`m_` か否か）の
どちらを採るかは別の争点として残る。**キーが `m_` でないこと**を選出職の判別に使うなら、
この計測の母集団と判別条件が一致するので、追加の分類器は要らない。
