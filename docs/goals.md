# open-gikai の目的

起草: 2026-11-21（AI。人のマージで合意）。数字の出典は GSC（open-gikai.net、2026-08-21〜11-18）と #106 のコメント。
線の数字はすべて提案で、合意前の仮置き。

## 大目的

- ビジョン: 国会で誰が何を言ったかを、原文に戻れる形のまま、専門家でなくても読めるようにする
- 対象の人: ニュースや検索で国会の議論・発言者（議員・官僚・参考人）が気になった一般の人
- 価値: 発言そのものの要旨を読み、原文の会議録で確かめられる
- 非目標: 検索向けの薄いページを量産しない（日付だけの更新・付加価値の薄い要約・自動生成のまとめページの大量出稿をしない）／特定の党派・議員を選んで持ち上げたり叩いたりしない（全発言を同じ処理にかける。CLAUDE.md の Summary Layer Invariants）／要約層に会話 UI を入れない
- 価値の指標: 検索などで着地した訪問のうち、発言の原文リンクか読みやすさの切替まで進んだ割合（未計測。計測が入るまでは GA4 の engagementRate で代用し、10-11〜11-07 は 43.1%）

## 手段の仮説

### H1 会期中は人物名・論点の検索で来てもらう

- 種類: GTM
- 当たっている証拠: 検索の着地はほぼ人物ページ（/m/）と論点スレッド（/t/）。28 日の CTR は 2.65%（08-21〜09-17）→ 3.71%（10-22〜11-18）に上がり、人物クエリ上位 5 件のクリックは 0 → 5 件（#106）。直近 7 日（11-12〜11-18）はクリック 50・表示 1,528 と伸びている
- 外れの合図: 2026-11-14〜12-11 の 28 日の検索クリックが 140 未満のまま（直近 28 日は 154、前期 08-21〜09-17 は 191）か、表示だけ伸びて CTR が 2.5% を下回る（期日: 2026-12-14）
- 予算: 作業役 6 件まで
- 露出の指標: GSC の表示回数とクリック数（28 日）
- 価値の指標: 検索から着地した訪問の、原文リンクか読みやすさ切替まで進んだ割合（計測前は engagementRate。40% を下回ったら露出だけ伸びていると見る）
- 次の見直し: 2026-12-14

### H2 着地ページから原文まで一段で届ける

- 種類: UI/UX
- 当たっている証拠: 弱い。engagementRate は 45.2% → 37.9% → 43.1% と揺れ、トップと /members の着地は 25.5%・10.0% と低い（#106）。どこで離れているかはイベントが無く分からない
- 外れの合図: 導線を変えて 4 週たっても、価値の指標が変更前から 2 ポイント以上動かない（期日: 2027-01-31）
- 予算: 作業役 4 件まで
- 露出の指標: 対象ページ（/m/・/t/）の着地数
- 価値の指標: 同じページでの原文リンクか読みやすさ切替まで進んだ割合
- 次の見直し: 2026-12-14
  - M1 の結果と計測の有無を見て、中目的にするか決める

### H3 会期のまとめページを検索の入口にする

- 種類: 何を作るか
- 当たっている証拠: まだ無い。/session/222 は 11/10 に公開したばかりで、成立した法律の節（#106 の P2、期限 12/19）は未実装
- 外れの合図: 1 会期 1 ページのまま、公開から 6 週で /session/222 の検索クリックが月 10 件未満、かつそこから /t/ へ進む訪問が 2 割未満（期日: 2027-01-31）
- 予算: 作業役 3 件まで（ページを会期ごと以外に増やすのはこの仮説が当たってから）
- 露出の指標: /session/222 の GSC 表示とクリック
- 価値の指標: /session/222 から /t/ へ進んだ訪問の割合
- 次の見直し: 2027-01-31

### H4 毎日の正しい更新を価値の前提として守る

- 種類: 何を作るか
- 当たっている証拠: Daily Batch は直近 40 回すべて成功（2026-11-21 時点）。一方、破損ファイル 1 つで朝の公開が止まる経路（#76）や、成功した deploy を失敗と報告する経路（#94）などが未対応で残る
- 外れの合図: 塞いだ穴に由来する障害が対応前後とも 0 件で、読者に見える欠落・誤表示も 0 件なら、予防の追加は止めて予算を M1 側へ回す（期日: 2027-02-28）
- 予算: 作業役 6 件まで
- 露出の指標: 最新スレッドの日付と NDL の公開日の差（日数）
- 価値の指標: 読者に見える欠落・誤表示の件数（月）と、Daily Batch の失敗件数（月）
- 次の見直し: 2027-01-31

## 中目的

### M1 臨時国会（〜12/12）の人物・論点ページで検索クリックを前期の水準に戻す

- 試す仮説: H1（H2・H3 は M1 の結果と計測の整備を見て次の中目的で試す）
- 当たりの線: 2026-11-14〜12-11 の 28 日の検索クリックが 181 以上で、engagementRate が 43% 以上
- 外れの線: 同じ期間の検索クリックが 140 未満
- 予算: 作業役 6 件まで（判定は 2026-12-14）
- 親 issue: #106

### M2 毎朝の公開を黙って欠けさせない

- 試す仮説: H4
- 当たりの線: 2027-01-31 までに M2 の sub-issue を閉じ、その間の読者に見える欠落・誤表示が 0 件
- 外れの線: 予算 6 件を使い切っても sub-issue が半分以上残るか、同じ期間に読者に見える欠落が 1 件以上起きる
- 予算: 作業役 6 件まで
- 親 issue: #122
